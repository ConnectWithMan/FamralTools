Frequently Asked Questions

What does RAW mean?
The RAW file contains uncompressed pixel bytes in RGBA order. It does not include image headers or metadata.

Can I open RAW files directly?
RAW files are generally not viewable by standard image viewers. They must be imported by tools or code that know the image width and height.
